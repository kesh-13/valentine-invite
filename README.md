# 💖 Valentine Invite

A playful and aesthetic Valentine invitation website that lets you create a personalized link and QR code to ask someone special to be your Valentine 💌

Designed to feel smooth, cute, and a little mischievous.

---

## 🌸 Live Website

[![Open Valentine Invite](https://img.shields.io/badge/💖%20Open%20Valentine%20Invite-ff69b4?style=for-the-badge)](https://kesh-13.github.io/valentine-invite/)

---

## ✨ Overview

Valentine Invite is a simple web experience where you:

- Enter your name and your Valentine’s name
- Instantly generate a shareable invite link
- Get an auto-generated QR code for easy sharing
- Send them to a Valentine page where saying **NO is basically impossible 😈**

Everything runs client-side and works seamlessly on GitHub Pages.

---

## 🎨 Features

- Light mode and AMOLED dark mode
- Animated theme toggle
- Smooth page transitions
- Floating heart background
- Auto-copy invite link
- Theme-aware QR code generation
- Mobile haptics for interactions
- Fun YES / NO interaction on Valentine page
- Fully responsive and mobile-friendly
